# Backend Interview Prep — 300 Questions

A topic-organized study guide built from your resume (Backend Engineer, ~2 YOE: NestJS, Postgres, Redis, Kafka, MQTT, AWS, Keycloak, RAG/LangGraph).

Each question is structured as:
- **Answer** — explanation with the *why*, not just the *what*
- **Code / diagram** — where it actually teaches something
- **Follow-up 1 & 2** — the questions interviewers ask after the canned answer

Treat this as a textbook, not a flashcard deck. Read, close the file, then say the answer out loud as if a panel is listening. The follow-ups are where senior engineers and hiring managers actually live.
